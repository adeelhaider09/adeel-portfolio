Agentic delivery workflow

How I shipped client work across 15+ stores. Guardrails throughout: feature branches only, no direct pushes to live themes, every live change verified.

Step 01

Read

A browser agent opens the ClickUp task, comments and reference recordings.

Step 02

Branch

A dedicated git branch and preview theme for the task.

Step 03

Build

Claude Code builds with me; Figma MCP supplies exact tokens and specs.

Step 04

Verify

Preview checked at desktop and mobile widths, proof screenshots captured. Codex reviews.

Step 05

Ship

Pull request, review, merge, then verified again on the live store.

shopify-order-sync

Receives HMAC-verified Shopify order webhooks, stores each exactly once in Postgres, processes them with a retrying worker and serves them through an authenticated, paginated REST API.
