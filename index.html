About

Engineering depth, delivery ownership

I am a team lead and senior full stack developer with 8+ years building, integrating and delivering ecommerce platforms for brands across North America, Europe and Asia. Today I lead the HubSpot and ecommerce team at Computan. From 2022 to 2026 I was Senior Ecommerce Developer at Kikstart Ecom (Canada), shipping Shopify Plus work for brands such as Spaze, Direct2Lab, Waydoo and Foremost Hat Shop.

My work sits between engineering and delivery. I translate business requirements into technical specifications and developer-ready tasks, review code and set standards, and stay close enough to the codebase to debug a production issue myself. Every change goes through its own branch, a preview theme, review, a pull request and a verified live release.

On the backend I work in Node.js and TypeScript — Express, Fastify and Remix services, custom Shopify apps and extensions on the Admin and Storefront APIs, webhook handlers and workers, PostgreSQL. On the frontend it is Liquid and Online Store 2.0, React and Next.js and headless Hydrogen. I also own technical SEO, Core Web Vitals, GA4 / GTM tracking and HubSpot CMS and CRM builds.

I am an AI-native engineer. Claude Code is my main engineering environment, with custom skills, project memory and MCP connections to Figma, Shopify and ClickUp; Codex handles parallel tasks and code review; and a browser agent checks preview themes and gathers proof before anything reaches a live store.

designecommerce functionalaccessibilityperformance contentreport
  • Specialised agents test Shopify stores in Chrome, Edge and mobile emulation, with BrowserStack for real iOS and Android. The functional agent really clicks through add-to-cart, search and mobile navigation.
  • Evidence-gated reporting: every defect carries device, browser, URL, severity, expected vs actual, repro steps and an annotated screenshot of the element. Findings under 70% confidence go to a human-review queue.
  • Design compliance: Figma and CSS design tokens compared with live computed styles, plus Figma frame export for side-by-side review.
